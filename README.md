## 🛠 آموزش نحوه اتصال به پروکسی تلگرام (MTProto)

برای استفاده از پروکسی های قرار داده شده در کانال `@SalamProxy` نیازی به تنظیمات پیچیده نیست:

1. وارد کانال **[SalamProxy](https://t.me/SalamProxy)** شوید.
2. روی دکمه **«اتصال به پروکسی»** یا لینک `tg://proxy?...` زیر هر پست کلیک کنید.
3. در پنجره باز شده، گزینه **Connect Proxy** را بزنید.
4. پس از نمایش علامت سپر (تیک دار) در بالای صفحه تلگرام، اتصال شما برقرار است.

### نکات فنی برای رفع مشکل اتصال (Checking یا Ping بالا)
* **بروزرسانی تلگرام:** مطمئن شوید از آخرین نسخه رسمی تلگرام (Android, iOS یا Desktop) استفاده می کنید؛ نسخه های قدیمی از پروتکل های جدید FakeTLS پشتیبانی نمی کنند.
* **تغییر وضعیت شبکه:** در صورت عدم اتصال اولیه، حالت هواپیما (Airplane Mode) را یک بار روشن و خاموش کنید تا IP اینترنت شما تغییر کند.
* **تست چند سرور:** به دلیل اختلالات مقطعی روی برخی دیتاسنترها، همواره ۲ یا ۳ پروکسی فعال را در لیست پروکسی های تلگرام خود ذخیره داشته باشید.

## ⚙️ ساختار فنی پروتکل MTProto FakeTLS
پروکسی های معرفی شده در این پروژه بر پایه استاندارد **MTProto Proxy** همراه با لایه **FakeTLS** پیکربندی می شوند. این تکنیک باعث می شود ترافیک تلگرام شبیه به ترافیک عادی وب گردی (HTTPS) به نظر برسد و در برابر سیستم های فیلترینگ هوشمند (DPI) مقاومت بسیار بالاتری داشته باشد.
