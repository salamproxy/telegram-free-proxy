# پروکسی رایگان و پرسرعت تلگرام (MTProto Proxy) 🚀

مجموعه پروکسی‌های ضد فیلتر و پرسرعت تلگرام (پروتکل FakeTLS) با پینگ پایین، سازگار با اینترنت **همراه اول، ایرانسل، رایتل و مخابرات**.

---

## 🌐 مشاهده لیست پروکسی‌ها و اتصال با یک کلیک (بدون فیلترشکن)

به دلیل محدودیت لینک‌های مستقیم در صفحات مارک‌داون گیت‌هاب، برای استفاده از **دکمه اتصال خودکار به تلگرام** و **کپی سریع لینک پروکسی‌ها**، وارد صفحه اختصاصی پروژه شوید:

👉 **[ورود به صفحه اتصال مستقیم پروکسی تلگرام](https://salamproxy.github.io/telegram-free-proxy/)**

---

## 📢 کانال تلگرام آپدیت ساعتی پروکسی‌ها

برای دریافت لحظه‌ای سرورهای جدید و جلوگیری از قطعی، عضو کانال تلگرام ما شوید:

* **لینک کانال:** [https://t.me/SalamProxy](https://t.me/SalamProxy)
* **نسخه پیش‌نمایش وب:** [https://t.me/s/SalamProxy](https://t.me/s/SalamProxy)

### حمایت از مخزن ⭐
اگر پروکسی‌ها برای شما کاربردی بود، با زدن دکمه **Star (ستاره)** در بالای صفحه از ادامه فعالیت پروژه حمایت کنید.
