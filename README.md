## 🛠 آموزش نحوه اتصال به پروکسی تلگرام

1. از جدول بالا روی لینک **«اتصال به پروکسی»** کلیک کنید.
2. در صفحه باز شده دکمه **Open Telegram** و سپس **Connect Proxy** را بزنید.
3. اگر یکی از پروکسی‌ها در حالت `Checking` ماند، گزینه بعدی را از جدول امتحان کنید یا وارد کانال **[@SalamProxy](https://t.me/SalamProxy)** شوید.

### رفع مشکل اتصال و پینگ بالا
* **بروزرسانی برنامه:** مطمئن شوید از آخرین نسخه رسمی تلگرام استفاده می‌کنید (نسخه‌های قدیمی از پروتکل FakeTLS پشتیبانی نمی‌کنند).
* **تغییر IP شبکه:** در صورت عدم اتصال، حالت هواپیما (Airplane Mode) را یک بار روشن و خاموش کنید.
